# FAQ

## Can I choose how much memory my server gets?

No. It is calculated from the server type, plugins, mods and player limit, and limited by the administrator's minimum and maximum. See [Creating a server](/docs/creating-servers#memory).

## Why can I not create a Vanilla server?

The list depends on what the installed proxy hookup can configure. Modded and hybrid types are available and set up for the proxy automatically. Ask an administrator if a type you need is missing.

## How many servers can I create?

Three by default. An administrator can change your quota.

## Why can I not upload files or edit them?

Uploads and direct editing are off by default. Switch them on in the **Files** tab of your server (the owner can). Administrators always can.

## Does it work with Bedrock and Education Edition?

Yes when the proxy runs Geyser (Bedrock) or EduGeyser (Education Edition). See [Joining a server](/docs/joining).

## Can I move my existing server in?

Administrators can import existing servers and proxies without changing their files. See [Existing servers](/docs/existing-servers).

## Is my world safe when I change versions?

Upgrading works; downgrading and moving across 1.17 or 26.1 do not. Always back up first. See [Worlds](/docs/worlds).

## Why does the dashboard say Starting for so long?

Large modpacks and first starts download and unpack a lot. Read the console for progress.

## Where are my files?

In the storage folder, in a folder named after your server's id or name. See [Storage and permissions](/docs/storage-and-permissions).
